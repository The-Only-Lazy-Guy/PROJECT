# Minimal install for SFT training + eval + GGUF export on a rental GPU.
#
# IMPORTANT: most rental boxes (RunPod, Lambda, Vast) ship a CUDA base image
# with torch + CUDA toolkit ALREADY installed (often torch 2.11 + cu130 in
# 2026). Do NOT let pip downgrade torch — it will break ABI compatibility
# with the box's CUDA libraries and trigger flash-attn build failures.
#
# Two-step install on a torch-preinstalled box (use this on the rental):
#
#     # 1. unsloth, but DO NOT touch the existing torch
#     pip install --no-deps unsloth
#
#     # 2. dependencies that are compatible with whatever torch is there
#     pip install -r requirements-train.txt
#
# On a clean box with no torch yet, install unsloth's pinned bundle first
# (pick the line matching your CUDA + GPU), then `pip install -r ...`:
#
#     pip install "unsloth[cu121-ampere-torch240]"     # cu12.1 + Ampere + torch 2.4
#     pip install "unsloth[cu124-ampere-torch251]"     # cu12.4 + Ampere + torch 2.5.1
#     # then the deps file below
#
# Either way, DO NOT install flash-attn. unsloth falls back to PyTorch SDPA
# attention, which is nearly identical speed on a 4B model at 4K context
# and avoids a 30-minute source build that frequently fails on rentals.

# Core libs unsloth needs at runtime. Versions chosen to be compatible
